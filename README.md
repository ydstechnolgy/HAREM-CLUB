# Harem Club

Logiciel de gestion du Harem Club : les serveuses notent les boissons de chaque table sur leur téléphone,
le gérant valide chaque sortie au bar et encaisse sur le PC, le patron suit tout à distance.

- `SUPABASE/` : scripts de la base de données (voir `SUPABASE/README.md`)
- Logiciel Flutter (PC Windows, APK Android, web) : à venir
